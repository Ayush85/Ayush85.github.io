# Ayush85.github.io

Personal site of Ayush Shrestha, a full stack and DevOps engineer in Kathmandu.

A static site with no build step: `index.html` and `css/style.css`. Edit those two files and push to `main`; GitHub Pages serves the repository root.

Fonts (Schibsted Grotesk and Source Serif 4) load from Google Fonts, with system fonts as the fallback.
